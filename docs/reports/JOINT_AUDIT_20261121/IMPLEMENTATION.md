## 本轮落地口径

- 来源候选池是可扩展的：默认只取「我们」的许愿星、当日记忆、存档对话、重要照片/聊天截图、日常原帖和预留留言；客厅独立启用且默认关，family 只预留。作品、表情包不作为来源。一个 asset 若确实具备独立的照片成员关系，则按该关系核准，不能因移除另一集合而改写它。
- 号码牌已生成后固定身份及修订，不因新增候选、改版、撤权或删除替补。新来源通过 Host 的受信 `HeartbeatSourceAdapter` 登记，不让模型或普通 HTTP 调用者注册来源。
- 当日随机记忆由独立 `heartbeat_memory` 任务在北京时间零点确定至多一条。与普通自动浮现的 prompt、作业、输入、回执、状态和聊天隔离；复用现有调度器及已配置 Sol Responses 的基础传输。乔乔明确批准发送最多四条已具资格的候选 ID 与每条最多 1500 字的正文。选择成功只持久 ID、修订、业务日、计划日界与实际完成时刻、回执身份；抽卡只读取当日选择。首次真实交付才使用共同 30 天冷却，无可靠未交付证据的 unknown 不释放。
- 既有调度器每 15 秒轮询，日界窗口为首分钟；系统休眠、停机、上一单飞后台任务跨越整个窗口或来源/报价故障，均如实记未完成，不在白天伪造零点选择。仅源准备任务可在聊天保温睡眠窗口执行，不发话、不占主会话执行槽；普通心跳的睡眠门不变。
