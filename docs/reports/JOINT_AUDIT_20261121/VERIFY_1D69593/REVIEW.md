## 二、仍有问题

### P1 · 五类已提交的源端动作仍不在朋友圈【高，A/X】

**星业务。** 新窗发现 wishstar_read 和对应写工具。用char身份读对方的请求、对方的递星以及自己的隐藏星，直接使用读回的合法对象 ID。接着回应请求 not_now、接住对方递星，再把自己的一颗星递过去，最后沉默。API direct 和 SDK deferred 经真实 Superposition ASGI 路由、授权及临时数据库完成。三笔写请求均 HTTP 200，读回请求为 rejected、原递星为 completed、星为 SHARED，反向递星为 offered。Host 的 actions 却是空数组，朋友圈只保留心跳状态和结束说明。

**记忆业务。** API deferred 和 SDK direct 经正式 M 能力入口用临时绑定创建两条记忆；随后用两条真实回执中的 memory_id 建立关系。只做建立的一组可从 M 查到关系。再走撤销分支，memory_correct 用刚返回的 relation_id 撤销同一关系，有源回执，独立读取确认关系已撤。两组朋友圈都能显示记忆、计划及 I，均缺“建立记忆关系”和“撤销记忆关系”。

**位置与修法。** E 的 `apps/host/src/capabilities/executor.ts` 通过描述符启动动作登记。星的三个入口见 `modules/wishstar/module.ts` 的 wishstar_respond_request、wishstar_accept_offer、wishstar_offer_star；记忆见 `modules/memory/module.ts:492` 与 `:527`。这些当前合法写分支没有把权威回执送入整轮投影。沿原执行器、事件/outbox 和源回执补齐，登记真实动作、源对象、修订或等价操作身份；按权限生成可读模板。保留 reads、失败、未知和同键重传各自语义。复验应逐项核对源状态、Host 行为行、一条朋友圈内的顺序、无正文结束、回执丢失后只补引用。确认这五种之外的操作请用实际业务回执逐一判定。

### P2 · 聊天工具已经发话并正常完成，投影仍记为 interrupted【中，A】

两驱动都在心跳中合法调用 chat_send_text，随后 background_complete(done)，零抽卡。正式消息一条，朋友圈能读到原话，run 和 turn 正常完成，投影内 terminal.status 也是 completed，外层 state 却为 interrupted。页面结束文案为“本轮结束。”。在正式提交后、调度最终收账前强停再冷启动，发言仍恰好一次，run 正常完成，恢复没发模型请求；错误的投影状态仍在。未观察到回话丢失或重复。

`apps/host/src/modules/heartbeat/runtime.ts:369` 只以本轮 `heartbeat:<run>:reply:...` 名称识别说话，chat_send_text 由正式聊天发布路径生成另一类消息身份，随后在 `:384` 落入 interrupted。由回合所有者按同 turn 已正式发布的助手消息确定无卡发话状态，保留明确取消/失败优先级，并维持未抽时 noop 的现行拒抽语义。覆盖自然正文、工具发话、两者并用、done/noop/取消、重启不重复发布。

### T1 · 历史评测的本机路径和旧选择器断言需要维护【测试，不计产品缺陷】

上次把这 5 项归因为缺历史材料，判断有误。两份 M 测试写死了另一台机器的 `/Users/owner/Projects/...`。本机在现有 devspace-workspace 找到了同一评估脚本和 run4、4b、4c、4d 四份历史合成结果。本轮对测试临时副本只改材料路径，阻断网络、不给凭据，只读取已有评分，不执行真实评估脚本的 main。

**原五项实际为 4 通过、1 失败。** 保守默认阈值通过，失败发生于历史实验阈值 0.45 的 S11。旧断言要求一个已合格候选因另一个 UNKNOWN 候选而全部弃选；现行 v5 按用途选择，可保留已合格的 a11，未核日期的 b11 仍为 UNKNOWN。诊断展开后，同一用例中旧“全弃”预期及其汇总名单两处不一致（209、222 行）。独立运行现行选择器 22 项全部通过。现行实现与测试见 M 的 `backend/mariposa/surfacing/selection.py:24`、`tests/unit/test_surface_selection_judge.py:109`。修复两份测试的材料定位，将历史 v2 预期和现行合同分别标清；勿把 0.45 用作生产阈值，或为旧断言改回已经退役的选择器。
