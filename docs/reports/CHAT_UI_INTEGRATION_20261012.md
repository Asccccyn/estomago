# 聊天界面接入 · 2026-10-12

将用户提供的 Figma Make 聊天页面融入 estómago 现有原生 HTML/JS 前端，不引入第二套 React 应用。生产界面不带演示消息、虚构模型、固定 token 或缓存命中率。

## 本批行为

- 消息、SSE、思考摘要、整轮实际用量、停止、历史翻页、修订、路由处理及人工历史选集沿用现有接口。
- 顶部模型与档位读取实际设置；非 OpenRouter 通道显示已核实的实际模型并禁用不适用的 OR 配置操作。
- 相册、图片文件、相机走真实资产上传；附件单独发送可用。重试冻结完整请求与附件，成功只清除本次已发送条目。
- 语音输入录音后上传 chat_voice，调用宿主转写端点；宿主使用核实过的 Siren REST 协议。可信转写经新增 schema 27 表持久化，并在发送时复制到消息修订；客户端不能伪造转写。旧修订不回写。
- 活动与记录、系统通知、工作台后台任务和上下文容量读取真实后端；容量未知时不显示假百分比。
- 手机可见视口变化保持输入栏可见；读旧消息时不强制跳底。消息动作宽度恢复 27 px，发送圆圈为 28 px。Enter 只换行，发送只通过独立按钮。

## 验证

- 类型检查通过，浏览器脚本语法通过。
- 完整串行回归第二次运行：98/99 文件通过；唯一失败为已有超大请求测试的 fetch 连接失败。随后独立串行重跑集成批次 12/12 通过，其中包含该用例。单元与合同批次均在完整运行中通过。
- 隔离 mock Host + 本地模拟 ASR 完成 13 项浏览器检查：空历史、中文输入、多行保存/回复、修订、模型设置、上下文、工作台、单图片发送、语音真实字节播放与可信转写、键盘模拟、按钮尺寸、三种手机宽度、无脚本异常。
- 所有测试使用独立临时 ESTOMAGO_HOME；未调用真实外部模型或语音服务。真实 iPhone Safari 键盘行为尚未实机验证。

## 限制与部署边界

- 实时语音通话与戳一戳没有当前后端合同，未虚构实现。普通文档附件没有现成聊天格式，文件入口仅接受支持的图片。
- 语音服务是否可用取决于现有 Siren 地址、服务凭据引用与合同版本；本批不修改这些配置。available=配置就绪，不代表已进行真实服务探针。
- 未修改登录页面的既有未提交变更，也未删除生产历史。仅代码接入及新增迁移，不将测试夹具写入生产。
