# 分批施工索引

严格顺序：P00 → P01 → P02 → P03 → P04 → P05 → P06 → P07 → P08 → P09 → P10。

- P00：基线与隔离。
- P01：叶类型、定义来源、等价快照。

- P03：完整语音/深听组合，不改实时协议。
- P04：其他现有工具按域逐项迁移。
- P05：消息事务挂点与同轮上下文。
- P06：唤醒/心跳/工具共用执行边界。
- P07：HTTP、装配、启停。
- P08：真实场景与扩展演练。
- P09：旧路径退役、防回退。
- P10：冻结交付，GLM5.3与Astra独立复核。

每卡内子步骤是执行单位，不把整张卡做成一个不可审查的大补丁。原则上每次只动一个职责，影响文件超过当前子步骤列出的范围时先写原因；不要机械限制为固定行数。

每次续做读：00 → RESUME → 当前卡 → 当前卡引用的合同 → git状态。不是每次重新读整本历史文档或重复生成架构。

当前卡阻塞而后续确实不依赖其结果时，可做只读准备/独立机械任务；不可绕过关键接口缺口先硬接功能。
