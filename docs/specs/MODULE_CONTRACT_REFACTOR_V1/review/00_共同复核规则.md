# 共同复核规则

复核对象必须是同一冻结候选SHA与同一来源基线。先看diff和真实入口，再看实施者报告；不能只复述GLM_DELIVERY。

复核默认只读，不部署/不付费/不改生产/不修改兄弟仓。可执行07已分类的定向测试，不擅自跑整个旧集或扩大极端范围。

每个发现必须写：ID、候选SHA、路径:符号/行、当前可达入口、最小正常操作、预期与实际、影响、建议归属、证据等级。类型检查或AST只算结构证据，不等于运行正确；fake transport算离线合同，不等于生产。

优先级：BLOCKER=当前主功能/权限/费用/历史不变式破坏；MAJOR=真实正常场景不能完成或模块接口仍未接通；MINOR=合理维护改进。没有当前路径的未来风险写建议，不升级成无限防御任务。

不要为了没有循环import而禁止所有回调；不要把声明式装配当业务耦合；不要只看拆了多少文件。必须检查修改局部化、数据正本与真实组合。

测试只需有限代表用例：正常流程+常见停止/重连/超时+必要权限边界。禁止构造不可能业务状态，也禁止反过来删除真实安全保护。

结论分为：通过/有阻断不通过/证据不足。没有运行的部分必须列出，不签“生产完成”。

补查通话memory_only精确资格及普通前台不新增背景报价门。两者都必须按当前代码/用户裁定保留，不能由模块注册默认扩大或收紧。
