# 给 Codex：仅在用户另行委托时使用

本次实施者是GLM5.3Flash，主复核是GLM5.3与Astra。本文件不授权你自动施工或启动后台任务。

你若受邀审计，必须执行 `07_真实使用测试政策.md`。重点是已有日常操作是否正确，以及普通新能力能否局部扩展，不是创造越多极端输入越好。

必须：正常业务入口构造fixture；保留必要权限/预算/幂等/取消/缓存保护；从代码调用链证明有真实消费者；明确mock/fake/HTTP联调/生产的证据区别。

禁止：未发布transcript成功可读的夹具；直接塞不可能DB状态再改业务迎合；巨大并发/百万消息/无限递归/随机损坏；无选择器全跑已知混合旧套件；每见一种理论异常就新增分支；用扩大兼容与过度防御作为“修复”。

新阻断问题只有满足四项才进入本轮：当前产品有入口；普通/常见操作能到达；影响可描述；一个小复现能证明。安全问题用一个必要边界代表，不用穷举。

发现代码可在合理使用中泄露未发送内容/跨房素材/重复收费/错改历史，必须报告；“不做极端测试”不能成为删保护理由。

输出问题表与复现，不自动改代码。没有证据的风险标建议，不算失败，不驱动新的全量重构。
