# 2026-10-21 时间、原文携带与换窗合同修订

本页是本轮现行补充，覆盖旧规格、旧注释中冲突的时间投影、手动强制评审及携带旧原文自动补记要求。原历史审计和数据库迁移保留。施工来源为用户提供的 `GLM_ESTOMAGO_CONTEXT_ROTATION_ROOT_FIX_20261021.md`；时间格式以随后在同一会话中确认的两行格式为准。

## 时间

```text
user_gap: PT26H7M
2026-10-21 08:33 Wed UTC+8
```

第一行是本条用户消息与上一条用户消息的真实发送间隔，不是处理时距最新用户消息的时间。保留小时和分钟，舍去秒，不进位；不足一分钟为 `PT0M`，无可信前驱时省略第一行。消息编辑不改变发送时间锚。第二行的日期、分钟、星期、时区来自同一个捕获时间点，按业务时区输出，午夜为 `00:xx`。内部结构化时间事实继续存入 `turns.time_context_json`。

唯一新投影入口为 `modelTimeContextText`。已发送历史、工具续轮和旧 JSON 快照原样保留；不清洗历史、不实现临时尾块方案 C、不放宽 append-only 守卫。

## 人工原文

确认选集的消息 ID、revision、hash 是唯一来源；不读取旧 wire 后删工具。装载缺失修订或 hash/角色/序号不符时报错，不交付部分结果。所选正文保留角色、序号锚及文字原样；历史图片仅既有占位，语音仅已有合法转写。

引导语按北京时间日历日分段：今天／昨天／前天附绝对日期，更早直接日期，未知或异常为“之前”。非连续选择插入“—— 原文片段 ——”。默认“说过的话”；现场不存在明确接续标记，不推断“没聊完”。引导语是宿主来源，不进入原文 manifest 或 hold 引用。

首次投影参照时间持久化于选集；初始轨迹与窗口激活、选集消费在一个事务中提交。已发送文本不随跨日、重启重新计算。全局时间解释规则只出现于固定规则中。

## 换窗

`context_selections.rotation_cause` 由服务端持久化，允许 `manual/capacity/identity_change/initial`。确认选集不改变原因。旧行保留 NULL：不能证明原因则 `ROTATION_CAUSE_UNKNOWN`，不凭猜测发模型请求；活动窗上明确的新手动请求可接管，并记录旧原因。

统一流程为：确定原因和源窗口 → 确认选集 → 身份／活动窗／房间互斥／评审／路由／未决写入核查 → 按原因评审 → 事务外准备 → 事务内再次核查并提交指针、选集和初始轨迹 → 恢复待答输入。切换失败不恢复输入；切换成功但入队前崩溃，可从 consumed 选集和当前目标窗口恢复一次。

手动换窗没有模型评审、自动 hold 或伪完成凭证，额外主模型请求为 0。容量原因继续使用原容量政策、提醒开关、范围去重、真实完成凭证和失败上限；允许 `no_new_hold`。已消费人工选集的精确消息修订只作为背景，不自动再次成为评审焦点。真正新见消息和自主 hold 不受阻挡；hold 成功指针仍仅按真实成功回执和原请求视野推进。

SDK 现有 runner 仅接受单条 prompt，不能保留人工选集的 user/assistant 协议角色。本轮不擅自扩展 SDK 接口：非空选集明确返回 `SDK_SELECTION_TRANSPORT_UNAVAILABLE`，旧窗和选集不动；不再静默消费后丢失选集。空选仍通过公共安全检查。缺少安全依赖也明确阻断，不回落到旧直转路径。

## 浮现

```text
回忆浮现：

[记忆引用 sf_…]
〈批准交付的正文原样〉
发生时间：2026-07-09

这是你的回忆，是你和user过去发生的事，不是现在正在发生的事。
```

多事件分别列正文、日期及短 ref，包尾声明只一次，无事件不生成空包。只有 exact 且合法的事件时间才投影具体日期／分钟，其余为“不确定”；不使用入库或召回时间。不改变已发送冻结浮现、详情授权和映射、生命周期、预算或供应商能力门。浮现仍仅放行现有 DeepSeek transport。

## 迁移与回退

v31 仅新增换窗原因与参照时间两列，旧记录默认 NULL，不改旧迁移。旧代码能读取新增列所在的表，但不能维护新原因合同，且会恢复手动强制评审行为；有 pending/confirmed 工作流时不宜直接回滚二进制。回退前需人工核对这些选集，保留账本、原文和冻结轨迹，不能通过删列、删数据或清审计回退。
