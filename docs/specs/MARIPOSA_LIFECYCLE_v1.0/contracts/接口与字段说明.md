# 契约说明：所有能力名均为实施目标

`episode.apply.input.schema.json` 仅验证输入形状；ACL、op 身份、合法状态转移、expected_revision、来源发布/路径/hash/偏移、终结位置与成员关系仍由正式服务验证。`corrected_state` 仅 correct 可用；terminal_source_ref 仅 close 或纠正 CLOSED 可用；示例 schema 已约束各动作字段白名单和原因码；GLM 在实际服务端保留同等约束。示例全为虚构 ID/hash，不得发送到生产；各示例是独立请求形状，不构成可直接执行的完整事件历史，运行测试须另建满足来源与版本条件的夹具。

## source.ingest（宿主代码调用）

请求固定：operation_id、获授权 stream_id、origin_instance、origin_conversation_id、有限 messages。每条 message 带 origin_message_id、revision、previous_revision（初版空）、conversation_sequence、predecessor 的精确消息/修订引用、sender/正式发布类型、occurred_at/received_at/published_at、text/可选资产引用与 content_hash。

认证 binding 的 stream grant 决定允许的 origin、room、speaker、scope；不从 request 接受作者权限。canonical hash 的规范化必须作为共享契约冻结（null/缺省、换行、Unicode、附件排序、时间格式均需有测试），不接受两端各算各的。

ACK：operation_id、committed_at、每条 origin/revision 对应的 source_conversation_id/source_message_id/content_hash、批次引用、完整性状态。同 op 重放同 ACK。status 只返回获授权的操作，不接受任意文件路径或 URL。

建议初值上限：每请求50条消息、规范化JSON正文总计1MiB；附件仅授权引用不内嵌无限 base64。该值是工程初值不是业务截断许可；超限明确报错并由 outbox 在稳定操作身份下分批，单条过大先走已有大对象路径，不静默丢文本。后续可按实测调整并更新契约版本。

## memory.hold（兼容扩展）

保留现有全部业务参数，新增 operation_id、source_selections（与 episode schema 共用的类型）。没有新增字段的旧手工 hold 保持原行为；宿主自动调用必须有 operation_id。带来源时：校验 + hold_in_tx + 全部 binding + completed op 同事务，绑定任一失败则回滚。

完成结果示意：`{operation_id,memory_id,version,binding_ids,committed_at}`；可重放标志与当前资源是否仍在分开。hold.status 按原操作查询，不返回私人正文，鉴权先于读取缓存。

## episode.get / episode.list

get：episode_id 与真实权限约束；list：scope_id、有限 states、cursor、limit。默认无叙事正文，返回当前 state/revision/短label/来源引用。source selections 太大时分页，缺省 limit 建议20、最大100，事件不被分页遗漏成“全都结束”。默认当前 scope，不默认为全库。

## context_review_complete（Host 工具，不是 Mariposa 写能力）

输入：review_id、decision=no_new_hold|holds_completed。Host 根据受保护上下文验证 scope/epoch/revision 与实际收据。模型不能选择自己的 scope、补一个任意窗口 ID 或自报 hold 成功名单。工具在无活动 review 时明确拒绝。

## 必须表达的错误类别

复用项目已有稳定错误码，缺失才新增：IDEMPOTENCY_CONFLICT、VERSION_CONFLICT、FORBIDDEN、SOURCE_NOT_READY、SOURCE_REVISION_CONFLICT、SOURCE_HASH_MISMATCH、SOURCE_RANGE_NOT_PATH、SOURCE_RANGE_OFFSET、SOURCE_SELECTION_TOO_LARGE、EPISODE_ALREADY_CLOSED、INVALID_TRANSITION、REVIEW_STALE、REVIEW_NOT_ACTIVE。

不得统一映射成200空对象或 no_new_hold。某错误码已存在则沿用，不照着文档再造近义版本。已提交操作的领域回执与未提交失败不同；未知结果不改名“未发生”。
