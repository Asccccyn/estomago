# estómago · OpenRouter 主接入与自主记忆执行包

制作日期：2026-10-05　产品：estómago　记忆服务：Mariposa　整理：林石见　实施：GLM

## 给 GLM 的任务

在现有 estómago 上实现 OpenRouter 主接入、原文可靠保存、主模型自主 hold、换窗前一次提醒、自动安全换窗，以及前台“记录”面板。Claude Agent SDK 与 MCP 保留。使用明确的一小时 Prompt Cache；不增加小模型、滚动摘要或第二套记忆。

**`01_执行架构.md` 是本任务唯一的规范正文。** 本包的配置、接口、提示模板、参考函数、场景夹具及验收文件是该正文的实现附件，不是可任选的架构路线。独立阅读本包即可开工，不需要拼接其他聊天方案。

先读规范正文，再读 `02_现场代码映射.md` 和 `03_施工与交付.md`，按工作包推进。字段名可映射现有实现，产品语义不可自行改写。普通工程问题由执行者处理；凭据、额外付费、跨仓库写入权限和生产部署等真实授权缺口必须明示，不以“先接通”为由绕过。

## 快速检查这个包

无需安装依赖，不联网，不读取 API key，不运行项目，不访问私人数据：

```sh
node scripts/verify-package.mjs
node --test tests/reference.test.mjs
```

要求 Node.js 18 或以上。交付时的参考函数测试结果见 `evidence/package-test-result.json`。这些测试只证明随包参考逻辑，不等于现有项目已实现或 OR 已实测。

| 文件/目录 | 用途 |
|---|---|
| `01_执行架构.md` | 产品语义、OR 参数、缓存、轨迹、换窗、MCP、权限、异常与前台规范 |
| `02_现场代码映射.md` | 已只读核对的两个仓库、实际符号和实现落点；非全量审计 |
| `03_施工与交付.md` | 有依赖关系的实施工作包、验证与部署关卡 |
| `04_来源与核实边界.md` | 官方资料、用户材料、代码观察与本项目设计的分界 |

| `prompts/` | 固定运行规则片段和临换窗提醒模板；不是char的身份正文 |

| `evidence/` | 本包检查证据、后续应用验收报告模板 |
| `SHA256SUMS` | 包内文件完整性校验，不包含自身 |

## 不得误读的四句话

原文自动保存，不等 hold。主模型可以不 hold，不追求聊天覆盖率。换窗前有一次明确选择机会，但允许零新增记忆。缓存用于复用计算，不负责保存原文、生成桶或保证无限上下文。
